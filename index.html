🐱 MiauFlix

Personal Movie & TV Tracker

MiauFlix is a private, non-commercial Android application created for personal use by two people.

The application allows users to track watched movies and TV series, create watchlists, rate titles, write notes, and view watching statistics.

MiauFlix plans to use the TMDB API to search for movies and TV shows and retrieve titles, descriptions, release dates, and posters.

This project is currently in development and is not available for public download.

This product uses the TMDB API but is not endorsed or certified by TMDB.
